Discord Every20 SMART

Краткая инструкция по замене и запуску на Windows. Подробности, все команды и диагностика — в README.md.

Обновление

  1. Остановите старого бота через Ctrl+C.
  2. Сохраните копию старой папки. Распакуйте новый ZIP в отдельную папку.
  3. После остановки скопируйте в новую папку старые .env и всю папку data. Старые файлы .py не копируйте.
  4. Запустите setup.bat, затем проверьте .env и запустите start.bat.
В .env нужен ваш ключ codex.sale: CODEX_SALE_API_KEY. Ключи и токены не входят в ZIP и не нужны для передачи нам. Включите ENABLE_MESSAGE_CONTENT=true и Message Content Intent в Discord Developer Portal.

Настройка канала

Если канал уже настроен, не нужно снова вызывать /bot setup. В нужном канале выполните:

/bot mode value:ai
/bot smart enabled:true
/bot smart_settings mentions:true arguments:true name:false activity:high
/bot periodic enabled:false
/bot status

Команда /bot periodic enabled:false выключает ответы по счётчику; SMART реагирует на обращения и конфликты. Настройки и промпт сохраняются в базе при обновлении.

Проверка

Отправьте с другого аккаунта тестовое сообщение, например кирик ты пидор или дура. Паузы и лимита числа ответов нет. Если ответа нет, вызовите /bot diagnose и смотрите logs/bot.log. В логе записаны ID и причины, текст сообщений не записывается.

Бот вызывает https://codex.sale/v1/responses. Проверьте модель и ключ по инструкции codex.sale. Тесты запускаются командой .venv\Scripts\python.exe -m unittest discover -s tests -v.
