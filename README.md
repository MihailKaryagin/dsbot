# Discord Every20 SMART — Windows

Бот отвечает по счётчику и, если включён SMART, сразу реагирует на обращение к нему или на конфликт в обычном текстовом канале. Настройки каждого канала хранятся в `data/bot.sqlite3`.

## Как заменить старую папку

1. Остановите старого бота через **Ctrl+C** и дождитесь завершения окна. Не запускайте две копии одновременно.
2. Скопируйте старую папку целиком в безопасное место. Особенно важны `.env` и папка `data`. Не присылайте `.env` или токены в чат.
3. Распакуйте этот ZIP в **новую** папку. Из старой папки скопируйте в новую `.env` и всю папку `data` **после остановки бота**. Не заменяйте новые `.py` старым кодом.
4. В новой папке запустите `setup.bat`. Он создаст `.venv`, установит зависимости и запустит тесты. Если у вас ещё нет Python, установите Python 3.12 с python.org и повторите.
5. Проверьте `.env`. Для codex.sale укажите `CODEX_SALE_API_KEY`, `CODEX_SALE_BASE_URL=https://codex.sale/v1`, `OPENAI_MODEL=gpt-6.1-sol`, `ENABLE_MESSAGE_CONTENT=true`. Старое имя `OPENAI_API_KEY` тоже читается, если в нём уже ваш ключ codex.sale. Ключ из скриншота в комплект **не включён**.
6. В Discord Developer Portal → ваше приложение → **Bot** включите **Message Content Intent**. У бота должны быть права **View Channel** и **Send Messages** в нужном канале.
7. Запустите `start.bat`. После строки о регистрации команд настройте канал командами ниже. Если команды не видны, проверьте `DISCORD_GUILD_ID` и установку приложения со scopes `bot` + `applications.commands`.

Старые фразы, промпт, счётчик и настройки каналов сохраняются. При запуске база обновляется автоматически. Переносите папку `data` целиком, а не только один файл SQLite.

## Рекомендуемая настройка канала

В нужном канале вызовите `/bot setup every:20` только если канал ещё не настроен. Затем:

```text
/bot mode value:ai
/bot smart enabled:true
/bot smart_settings mentions:true arguments:true name:false activity:high
/bot periodic enabled:false
/bot status
```

`/bot periodic enabled:false` убирает случайные ответы по счётчику; SMART продолжает работать. Если нужны и периодические реплики, включите их через `/bot periodic enabled:true` и выберите интервал через `/bot every`.

После настройки отправьте с другого аккаунта одно из тестовых сообщений: `пидорас`, `долбаеб`, `дура`, `кирик ты пидор`. При `activity:high` каждое может вызвать реакцию. Ограничений на число ответов и паузы между ними нет. Команда `/bot test` проверяет только генерацию ИИ, не распознавание оскорблений.

## Что понимает SMART

- Прямое упоминание бота или ответ на его сообщение при `mentions:true`.
- Имя бота как отдельное слово при `name:true`.
- Адресное оскорбление через «ты/вы», упоминание другого участника или ответ ему.
- Распространённые русские ругательства и варианты написания `ё/е`, регистра и части смешанных букв. Например, `долбоёб`, `долбаеб`, `пидор`, `пидорас`, `дура`, `идиот`, `дебил`.
- Соседние сообщения: после оскорбления от другого участника короткий грубый ответ считается продолжением конфликта.
- При `activity:high` отдельное грубое слово тоже может вызвать ответ. При `low` требуется явный адресат или развитие конфликта.

Это локальные правила, а не безошибочное понимание смысла. Обсуждение слова как цитаты и кодовые блоки обычно пропускаются. Ответ генерирует ИИ на основе до 20 последних сообщений канала. Логи сохраняют ID и причину решения, но не текст сообщений.

## Все команды

| Команда | Действие |
|---|---|
| `/bot setup every:20` | Включить канал и сбросить счётчик |
| `/bot phrases` | Изменить запасные фразы |
| `/bot prompt` | Изменить стиль и инструкцию ИИ |
| `/bot mode value:ai` или `phrases` | Выбрать режим |
| `/bot every number:20` | Изменить интервал периодических ответов |
| `/bot periodic enabled:false` | Выключить ответы по счётчику, оставив SMART |
| `/bot smart enabled:true` | Включить SMART |
| `/bot smart_settings` | Настроить `mentions`, `arguments`, `name`, `activity` |
| `/bot status` | Показать настройки, последнюю ошибку и решение |
| `/bot diagnose` | Показать причину последнего ответа или пропуска |
| `/bot test` | Приватный пробный ответ ИИ без изменения счётчика |
| `/bot pause` и `/bot resume` | Приостановить и продолжить канал |
| `/bot reset` | Очистить счётчик и контекст |

Команды настройки доступны владельцу сервера и пользователям с правом **Управление сервером**. SMART работает только в канале, где выполнен `/bot setup`, и только при режиме `ai`. Личные сообщения, ветки, вебхуки и сообщения ботов не обрабатываются.

## Если бот молчит

1. Проверьте `/bot status`: канал включён, режим `ai`, Smart `True`, ключ задан, `arguments=True`, `activity=high`.
2. Вызовите `/bot diagnose`, затем откройте `logs/bot.log`. Ищите `channel=<ID> message=<ID> decision=<причина>`.
3. Частые причины: `mode_is_phrases`, `arguments_disabled`, `message_content_disabled`, `empty_content_or_intent`, `ambiguous_insult_no_target`, `quoted_or_discussion`, `missing_send_permission`.
4. Если ответ пришёл из готовых фраз, смотрите «Последняя ошибка» в `/bot status`: ключ, баланс, доступ к модели, адрес `/v1`, таймаут или HTTP-код.
5. После исправления ключа, модели или намерения доступа перезапустите `start.bat`. После изменения настроек slash-командами перезапуск не нужен.

SMART и периодические ответы не ограничены таймером. Каждый ответ ИИ и команда `/bot test` отправляют запрос к API.

## API и конфиденциальность

Бот вызывает `POST https://codex.sale/v1/responses` с Bearer-ключом, `model`, `instructions`, `input`, `stream:false`, `store:false`. Название модели должно совпадать с её ID в `GET /v1/models`; доступность зависит от вашего ключа. Ключ и тело ошибки API не записываются в лог. При ошибке ИИ бот использует запасную фразу и показывает причину в статусе.

Контекст ИИ: до 20 последних сообщений включённого канала, отображаемое имя автора и до 600 символов текста каждого. Контекст хранится в памяти и сбрасывается при перезапуске. Изображения и вложения не скачиваются. Предупредите участников, что фрагменты переписки уходят внешнему сервису. `store:false` не является обещанием отсутствия любой служебной обработки у провайдера.

- [Документация codex.sale](https://codex.sale/docs)
- [Описание OpenAI Responses API](https://developers.openai.com/api/docs/guides/text)

Локальные тесты: `".venv\Scripts\python.exe" -m unittest discover -s tests -v`. Они проверяют правила, миграцию базы, антиспам, обработку сообщений и форму запросов. Для реальной проверки Discord и codex.sale нужен ваш собственный ключ и сервер.
