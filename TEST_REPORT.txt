Discord Every20 SMART — отчёт о проверке
Дата: 2026-10-13

Среда: Windows, Python 3.12.14, discord.py 2.6.4, aiohttp 3.13.2,
python-dotenv 1.2.1.
Команда: python -m unittest discover -s tests -v
Результат: 28 тестов, OK.

Проверено локально с имитацией внешних сервисов:
- старые команды и настройки, счётчик, сохранение БД и миграция SMART;
- реакции на «пидорас», «долбаеб», «дура», «кирик ты пидор»;
- варианты написания, прямое обращение, контекст конфликта и пропуск цитаты;
- отключение периодических ответов без отключения SMART;
- отсутствие паузы и лимита ответов даже при старых значениях таймеров в БД;
- причины решений в логах без текста сообщений;
- форма запроса к codex.sale /v1/responses, успешный ответ и ошибки;
- проверка разрешений Discord, отсутствие массовых упоминаний, защита от второго экземпляра.

Не проверялось: реальное подключение к Discord и платный запрос codex.sale —
для этого нужны личные токены и сервер пользователя. Успех локальных тестов
не гарантирует работу при неверных правах, ключе, модели или проблемах сети.
